# DK Color Picker

[English](README.md) | [한국어](README.ko.md)

Windows 10/11용 가벼운 휴대형 화면 색상 추출기입니다.

단축키를 누르고 화면의 원하는 색을 선택하면 즉시 클립보드에 복사됩니다. 프로그램은 트레이에 상주하며, 컴팩트한 **색상 도구** 창에서 조화 배색·최근 색상·즐겨찾기·유사 CSS 코드·WCAG 대비를 함께 확인할 수 있습니다.

## 다운로드

최신 배포판:

**https://github.com/danhk0612/DK-Color-Picker/releases/latest**

1. `DKColorPicker-win-x64.zip`을 받습니다.
2. 원하는 폴더에 압축을 풉니다.
3. `DKColorPicker.exe`를 실행합니다.

설치 과정이나 별도 런타임 설치는 필요하지 않습니다.

## 가장 빠른 사용법

1. `DKColorPicker.exe`를 실행합니다.
2. **Ctrl+Alt+C**를 누릅니다.
3. 원하는 색 위로 커서를 이동합니다.
4. 좌클릭하거나 **Enter / Space**를 누릅니다.
5. 선택한 복사 형식의 색상 코드가 클립보드에 바로 복사됩니다.

프로그램은 이후에도 시스템 트레이에 계속 상주합니다.

- 트레이 아이콘 더블클릭: **색상 도구 열기**
- 트레이 아이콘 우클릭: 설정 변경 / 종료
- 색상 도구의 X 버튼: 종료가 아니라 창 숨김

완전히 종료하려면 트레이 메뉴의 **종료**를 사용합니다.

## 색상 추출 화면 조작

| 동작 | 조작 |
| --- | --- |
| 색 선택 | 좌클릭 / Enter / Space |
| 취소 | Esc / 우클릭 |
| 1픽셀 이동 | 방향키 |
| 확대 배율 변경 | 마우스 휠 / + / - |
| 평균 추출 영역 변경 | 1 / 3 / 5 / 7 / 9 |

확대 배율:

`8x · 12x · 16x · 24x · 32x · 48x`

평균 추출 영역:

`1x1 · 3x3 · 5x5 · 7x7 · 9x9`

색을 고르는 동안에는 화면 캡처가 정지되어 있으므로 커서를 움직여도 원본 화면이 변하지 않습니다.

## 복사 형식

지원 형식:

`HEX · RGB · RGBA · HSL · HSV · HWB · CMYK · CIELAB · OKLCH · 사용자 템플릿`

RGBA의 알파값은 화면 픽셀에 투명도 정보가 없기 때문에 `1`로 출력됩니다.

복사 형식은 트레이 메뉴 또는 색상 도구 상단의 라디오 버튼에서 변경할 수 있습니다.

색상 도구에서 형식을 바꾸면:

- 현재 픽한 색이 새 형식으로 즉시 클립보드에 복사됩니다.
- 색상 도구 안의 모든 색상 코드가 같은 형식으로 바뀝니다.
- 이후 화면 픽과 색상 상자 클릭에도 같은 형식이 적용됩니다.

## 색상 도구

트레이 아이콘을 더블클릭하거나 트레이 메뉴의 **색상 도구 열기**를 선택하면 됩니다.

### 현재 색

큰 색상 상자는 가장 최근에 화면에서 픽한 색입니다.

색상 상자를 클릭하면 현재 복사 형식으로 즉시 복사됩니다.

상자 안의 **☆ / ★** 부분을 누르면 즐겨찾기에 추가하거나 제거합니다.

### 유사 CSS 코드

현재 색과 CSS의 148개 named color를 비교해 가장 가까운 이름을 표시합니다.

**유사 CSS 코드: color-name** 부분을 클릭하면 해당 CSS 색상 이름 자체가 클립보드에 복사됩니다.

### 배색

현재 픽한 색을 기준으로 배색을 종류별로 나누어 표시합니다.

- **보색**: +180° 1개
- **유사색**: -30° / +30° 2개
- **삼각 배색**: -120° / +120° 2개
- **분할 보색**: +150° / +210° 2개
- **사각 배색**: +90° / +180° / +270° 3개

각 색상 상자를 클릭하면 현재 복사 형식으로 즉시 복사됩니다. 배색 색상을 눌러도 현재 픽한 색은 바뀌지 않고 최근 색상에도 추가되지 않습니다.

### 최근 색상

최근 색상에는 **화면에서 실제로 픽한 색만** 들어갑니다.

- 최대 8개의 서로 다른 색을 저장합니다.
- 같은 색을 다시 픽하면 맨 앞으로 이동합니다.
- 최근 색상을 클릭하면 복사만 하고 기록을 다시 추가하지 않습니다.
- **최근 색상 정리** 버튼으로 목록을 비울 수 있습니다.

### 즐겨찾기

모든 색상 상자의 **☆ / ★** 부분으로 즐겨찾기를 켜고 끌 수 있습니다.

현재 색, 조화 배색, 최근 색상, 기존 즐겨찾기 어디에서든 추가할 수 있습니다. 즐겨찾기는 최대 8개이며, 8개가 찬 상태에서 새 색을 추가하면 경고를 표시하고 기존 즐겨찾기는 그대로 유지합니다.

즐겨찾기가 하나도 없으면 즐겨찾기 영역은 표시되지 않으며, 첫 즐겨찾기를 추가하면 자동으로 나타납니다.

## 컴팩트 창

색상 도구는 내용에 맞춰 높이가 자동으로 변합니다.

- 최근 색상이 적으면 필요한 행만 사용합니다.
- 즐겨찾기가 없으면 해당 영역을 숨깁니다.
- 첫 즐겨찾기를 추가하면 자동으로 창이 늘어납니다.
- 마지막 즐겨찾기를 제거하면 다시 줄어듭니다.
- 최근 색상을 정리하면 사용하지 않는 빈 공간도 바로 없어집니다.

가로 폭은 색상 코드가 읽히는 범위에서 불필요하게 넓지 않도록 유지합니다.

## WCAG 대비

현재 픽한 색을 배경으로 사용할 때 **흰색 글자와 검정 글자**를 각각 평가합니다.

각 글자색마다 대비비와 함께 다음 기준의 통과 여부를 `True / False`로 표시합니다.

- 일반 글자: WCAG AA 4.5:1, AAA 7:1
- 큰 글자: WCAG AA 3:1, AAA 4.5:1

따라서 선택한 배경색에 흰색 또는 검정 글자 중 어느 쪽이 적절한지 바로 판단할 수 있습니다.

## 트레이 설정

트레이 메뉴에서 다음 항목을 조정할 수 있습니다.

- 색 추출
- 색상 도구 열기
- 확대 배율
- 평균 추출 영역
- 복사 형식
- 전역 단축키
- **색 추출 후 항상 색상 도구 열기**
- **Windows 시작 시 자동 실행**
- 테마: 시스템 / 라이트 / 다크
- 언어: 한국어 / 영어
- 종료

기본 전역 단축키는 **Ctrl+Alt+C**입니다.

다른 프로그램과 충돌하면 트레이 메뉴에서 다른 단축키 프리셋을 선택할 수 있습니다.

## 사용자 템플릿

트레이에서 다음 메뉴를 엽니다.

**복사 형식 → 사용자 템플릿 편집**

기본 템플릿:

```text
{hex} / {rgb} / {rgba}
```

전체 형식 자리표시자:

```text
{hex} {rgb} {rgba} {hsl} {hsv} {hwb} {cmyk} {lab} {oklch}
```

구성요소 자리표시자:

```text
{r} {g} {b}
{hsl_h} {hsl_s} {hsl_l}
{hsv_h} {hsv_s} {hsv_v}
{hwb_h} {hwb_w} {hwb_b}
{cmyk_c} {cmyk_m} {cmyk_y} {cmyk_k}
{lab_l} {lab_a} {lab_b}
{oklch_l} {oklch_c} {oklch_h}
```

## 설정과 데이터 저장 위치

프로그램 설정:

```text
%LOCALAPPDATA%\DKColorPicker\settings.ini
```

최근 색상과 즐겨찾기:

```text
%LOCALAPPDATA%\DKColorPicker\colors.ini
```

Windows 자동 시작은 현재 사용자 계정의 `HKCU\...\Run`을 사용하므로 관리자 권한이 필요하지 않습니다.

원하면 EXE 옆에 다음 외부 번역 파일을 두어 일부 문구를 덮어쓸 수도 있습니다.

```text
locales\ko.ini
locales\en.ini
```

외부 파일이 없어도 한국어와 영어는 EXE에 기본 포함되어 정상 동작합니다.

## 문제 해결

### Ctrl+Alt+C가 동작하지 않음

다른 프로그램이 이미 같은 전역 단축키를 사용하고 있을 수 있습니다.

트레이 메뉴에서 다른 단축키 프리셋을 선택하세요.

### 창을 닫았는데 프로그램이 종료되지 않음

정상 동작입니다. 색상 도구의 X 버튼은 창만 숨기고 프로그램은 트레이에 계속 남아 있습니다.

완전히 종료하려면 **트레이 → 종료**를 선택하세요.

### EXE를 다른 폴더로 옮긴 뒤 자동 실행이 안 됨

자동 실행 설정에는 현재 EXE 경로가 저장됩니다.

프로그램을 옮긴 뒤 **Windows 시작 시 자동 실행**을 껐다가 다시 켜면 새 경로로 갱신됩니다.

## 소스에서 빌드

필요 환경:

- Windows 10/11 x64
- Visual Studio 2022 Build Tools 이상
- CMake 3.23 이상

빌드:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

결과:

```text
build\Release\DKColorPicker.exe
```

배포 ZIP 생성:

```powershell
./tools/package.ps1 -ExePath build/Release/DKColorPicker.exe
```

시작 시간과 메모리 사용량 측정:

```powershell
./tools/measure.ps1 -ExePath build/Release/DKColorPicker.exe -Samples 5
```

개발 상태와 후속 계획은 [ROADMAP.md](ROADMAP.md)를 참고하세요.

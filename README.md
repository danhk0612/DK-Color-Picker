# DK Color Picker

Windows 10/11용 초경량 화면 색상 추출기입니다.

ColorPick과 같은 빠른 사용 흐름을 목표로 하지만, 기존 프로그램의 코드나 자산을 사용하지 않는 독립적인 MIT 구현입니다.

## 현재 구현

- 네이티브 C++20 + Win32 API
- 설치가 필요 없는 단일 EXE
- 트레이 상주
- 전역 단축키
  - 기본값: Ctrl+Alt+C
  - Ctrl+Shift+C / Alt+Shift+C / Ctrl+Alt+P / F8 선택 가능
- 가상 데스크톱 전체 화면 캡처 후 화면 정지
- 다중 모니터 좌표 및 Per-Monitor DPI Awareness V2
- 8x / 12x / 16x / 24x / 32x / 48x 확대
- 1x1 / 3x3 / 5x5 / 7x7 / 9x9 평균 색상 추출
- 평균 영역과 현재 픽셀을 확대경에 구분 표시
- 방향키 1픽셀 이동, 휠 또는 +/- 확대, 숫자 1/3/5/7/9 평균 범위 변경
- Enter / Space / 좌클릭 선택, Esc / 우클릭 취소
- 복사 형식
  - HEX
  - RGB
  - HSL
  - HSV
  - HWB
  - CMYK
  - CIELAB
  - OKLCH
  - 사용자 정의 템플릿
- 사용자 정의 복사 템플릿 편집 창
- 메인 색상 도구 창
  - 현재 색상 카드
  - HEX / RGB / HSL / OKLCH 표시
  - 직접 색상 입력
  - 가장 가까운 CSS named color
  - 밝기/어둡기 톤 5단계
  - 보색 / 유사색 / 삼각 배색
  - 흰색·검정 대비 WCAG 판정
  - 최근 색상 최대 20개
  - 즐겨찾기 최대 20개
  - 최근/즐겨찾기 스와치 클릭 적용
  - 현재 색 즐겨찾기 추가/제거
  - 최근 목록 비우기
  - 즐겨찾기 팔레트 파일 내보내기
- 148개 CSS named color 전체를 CIELAB 거리로 비교
- 창을 닫으면 종료하지 않고 트레이로 숨김
- 트레이 더블클릭으로 색상 도구 창 열기
- 트레이 메뉴에서 색 추출 / 색상 도구 / 확대 / 평균 / 복사 형식 / 단축키 / 자동 시작 / 종료 설정
- 설정 및 색상 라이브러리를 LocalAppData에 저장
- HKCU Run 기반 사용자별 자동 시작
- 중복 실행 방지
- 정적 MSVC 런타임 사용으로 별도 런타임 설치 없이 실행

## 기본 사용법

1. DKColorPicker.exe를 실행합니다.
2. 프로그램은 트레이에 상주합니다.
3. Ctrl+Alt+C를 누릅니다.
4. 원하는 픽셀을 선택합니다.
5. 선택한 복사 형식의 값이 클립보드에 복사됩니다.
6. 트레이 아이콘을 더블클릭하거나 **색상 도구 열기**를 선택하면 현재 색을 자세히 확인할 수 있습니다.

픽한 색은 자동으로 최근 색상에 저장됩니다. 색상 도구 창의 X 버튼은 프로그램 종료가 아니라 창 숨김입니다. 완전 종료는 트레이의 **종료**를 사용합니다.

## 색상 도구 직접 입력

다음 형식을 사용할 수 있습니다.

    #09F
    #0099FF
    rgb(0, 153, 255)
    dodgerblue

직접 입력하거나 톤/배색/최근/즐겨찾기 스와치를 클릭하면 색상 도구의 현재 색이 바뀝니다.

### CSS 이름 근사

CSS의 148개 named color를 CIELAB 공간에서 비교해 가장 가까운 이름과 실제 named color 값을 표시합니다.

### 톤과 조화 배색

톤 단계:

- 흰색 50% 혼합
- 흰색 25% 혼합
- 원본
- 검정 25% 혼합
- 검정 50% 혼합

조화 배색:

- 보색 180°
- 유사색 -30° / +30°
- 삼각 배색 -120° / +120°

### WCAG 대비

현재 색과 흰색/검정의 상대휘도 대비를 계산하고 다음 기준을 표시합니다.

- AA 일반 텍스트: 4.5:1 이상
- AAA 일반 텍스트: 7:1 이상
- AA 큰 글자: 3:1 이상
- AAA 큰 글자: 4.5:1 이상

## 최근 색상과 즐겨찾기

색상 라이브러리는 별도 DB 없이 다음 파일에 저장됩니다.

    %LOCALAPPDATA%\DKColorPicker\colors.ini

정책:

- 최근 색상: 최대 20개
- 같은 색을 다시 선택하면 맨 앞으로 이동
- 즐겨찾기: 최대 20개
- 현재 색상은 버튼으로 즐겨찾기 추가/제거
- 최근 목록은 색상 도구에서 비울 수 있음

## 팔레트 내보내기

내보내기 대상은 **즐겨찾기 목록**입니다.

지원 형식:

- CSS Variables (.css)
- JSON (.json)
- Tailwind colors object (.js)
- GIMP Palette (.gpl)

예를 들어 CSS 출력은 다음 형태입니다.

    :root {
      --color-1: #3B82F6;
      --color-2: #EF4444;
    }

Tailwind 출력은 colors에 바로 넣을 수 있는 객체 형태입니다.

## 사용자 정의 템플릿

트레이에서 **복사 형식 → 사용자 템플릿 편집...** 을 선택합니다.

기본 템플릿:

    {hex} / {rgb}

전체 형식 자리표시자:

    {hex} {rgb} {hsl} {hsv} {hwb} {cmyk} {lab} {oklch}

구성요소 자리표시자:

    {r} {g} {b}
    {hsl_h} {hsl_s} {hsl_l}
    {hsv_h} {hsv_s} {hsv_v}
    {hwb_h} {hwb_w} {hwb_b}
    {cmyk_c} {cmyk_m} {cmyk_y} {cmyk_k}
    {lab_l} {lab_a} {lab_b}
    {oklch_l} {oklch_c} {oklch_h}

## 설정 저장

    %LOCALAPPDATA%\DKColorPicker\settings.ini

저장 항목:

- 확대 배율
- 평균 추출 범위
- 전역 단축키 프리셋
- 복사 형식
- 사용자 정의 템플릿

자동 시작은 현재 사용자 HKCU Run 항목을 사용합니다.

## 빌드

요구 사항:

- Windows 10/11 x64
- Visual Studio 2022 Build Tools 또는 그 이상
- CMake 3.23 이상

PowerShell:

    cmake -S . -B build -A x64
    cmake --build build --config Release

결과 파일:

    build\Release\DKColorPicker.exe

## 개발 방향

T01~T05에서 트레이 상주 코어, 픽커 품질, 색상 형식/템플릿, 메인 색상 도구, 최근/즐겨찾기와 팔레트 내보내기를 구현했습니다. 다음은 제품 마무리 단계입니다.

- 다크 / 라이트 / 시스템 테마
- 한글 / 영어 및 외부 번역 파일
- 전용 아이콘
- 릴리스 패키징
- 시작 시간 / 메모리 측정

자세한 순서는 ROADMAP.md를 확인하세요.

기능 동작의 참고 대상은 공개된 ColorPick 설명이지만, 본 프로젝트는 별도의 독립 구현이며 원 프로그램과 제휴 또는 연관되어 있지 않습니다.
